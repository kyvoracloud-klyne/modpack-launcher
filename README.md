# Mod pack launcher

Opening the program with no arguments shows the pack window. Play installs pack `modpack-2026` for one Cosmoteer session, then restores the Steam game files.

Pack updates come from the public repository `kyvoracloud-klyne/cosmoteer-modpack-2026`. Each release includes `manifest.json` and the archive it names. Launcher updates come from this repository. The release assets are `modpack-launcher-linux-amd64` and `modpack-launcher-windows-amd64.exe`.

This repository is private, so self-update needs `MODPACK_GITHUB_TOKEN` or `GITHUB_TOKEN`. The pack repository is public and does not need a token.
