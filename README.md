# Mod pack launcher

Opening the program with no arguments shows the pack window. Each pack is one row. Its page has a version menu. Play installs that version, enables and trusts every mod in `ModPackProfile/settings.rules`, and leaves the pack installed after Cosmoteer closes. Uninstall puts Standard Mods and the Bin proxy back. The Steam profile's settings are not changed.

Pack updates come from the public repository `kyvoracloud-klyne/cosmoteer-modpack-2026`. Each release includes `manifest.json` and the archive it names. Launcher updates come from this repository. The release assets are `modpack-launcher-linux-amd64` and `modpack-launcher-windows-amd64.exe`.

This repository is public. Launcher and pack updates do not need a token.
